# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a vulnerability

If you discover a security issue, please open a private security advisory on GitHub or email the maintainers directly instead of filing a public issue.

We will acknowledge your report within 72 hours and aim to provide a fix or mitigation plan promptly.
